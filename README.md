### Hi, I’m Brianna Baynard

**AI Governance & Non-Human Identity** · AIGP · SecAI+ · ISC² CC  
Pennsylvania · Open to remote

I build practical, testable controls for AI agents operating in regulated environments — especially healthcare voice workflows.

My work starts from a real operational problem I lived through on the payer side: **impersonation latency** — the gap between an AI agent initiating a call and the receiving party being able to verify that it is non-human *and* authorized. Most current systems leave that gap effectively infinite.

---

### Flagship Project

**[NHID-Clinical](https://github.com/NHID-Clinical/NHID-Clinical)**  
Open-source governance framework for non-human identity disclosure, pre-data-exchange authorization, deceptive-behavior detection, human escalation, and tamper-evident audit trails in healthcare AI voice agents.

- Deterministic policy engine + conformance test suite  
- Cryptographic agent identity layer (Ed25519 / NHID-Auth)  
- Live reference agents + platform adapters (Twilio, Vapi, Retell, Amazon Connect, etc.)  
- Mapped to NIST AI RMF, HIPAA, EU AI Act Art. 50, ISO 42001  

→ [nhid-clinical.org](https://nhid-clinical.org) · [Specification](https://nhid-clinical.org/specification.html) · [Simulator](https://nhid-clinical.org/simulator.html)

**Public comment submitted to NIST** (docket NIST-2025-0035-0026) — now part of the federal record.
